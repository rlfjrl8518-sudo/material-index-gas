영상 URL 일괄 변환

기존 등록된 영상(VID)의 URL을 Drive 재생 가능한 형식으로 일괄 변환합니다.
최초 1회 실행하면 됩니다.

API 키 관리

API 키는 Google Apps Script 스크립트 속성에 안전하게 저장됩니다.
저장된 키는 마스킹 처리되어 표시되며 원본 값은 노출되지 않습니다.
